### PAT_TRACE_BASIC_014: Downstream Trace
```ruby
def trace_downstream(start_node)
  queue = [start_node]
  start_node._seen = true
  
  while queue.any?
    node = queue.shift
    node.selected = true
    
    node.ds_links.each do |link|
      next if link._seen
      link._seen = true
      link.selected = true
      
      ds_node = link.ds_node
      if ds_node && !ds_node._seen
        ds_node._seen = true
        queue << ds_node
      end
    end
  end
end
```

### PAT_STRUCTURE_UPDATE_012: Update WSStructure
```ruby
def update_structure_from_array(structure, rows)
  raise 'Not WSStructure' unless structure.is_a?(WSStructure)
  structure.length = rows.length
  rows.each_with_index do |data, i|
    data.each { |key, val| structure[i][key] = val }
  end
  structure.write
end
```

## Common Result Fields

### InfoWorks (hw_) Networks
**Links/Conduits:**
- `us_flow`, `ds_flow`, `us_depth`, `ds_depth`, `us_vel`, `ds_vel`

**Nodes:**
- `depnod` (depth at node), `qnode` (flow at node), `dmaxd` (maximum depth)

### SWMM (sw_) Networks
**Links:**
- `FLOW`, `VELOCITY`, `DEPTH`, `VOLUME`, `CAPACITY`

**Nodes:**
- `DEPTH`, `HEAD`, `VOLUME`, `FLOODING`, `PRESSURE`
